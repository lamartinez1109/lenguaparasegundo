El explorador del tiempo

5 actividades (niveles), cada uno se desbloquea al completar el anterior
Mecánica "solo avanza si acierta": en cada ítem, el alumno no puede pasar al siguiente hasta responder bien (con pista/ayuda tras 2 intentos)
Animaciones: confeti al completar nivel, búho que baila, items que tiemblan al fallar

Las 5 actividades:

1) Ver verbo en 3 tiempos → indicar el tiempo pedido (ej: "corrió / corre / correrá → ¿cuál es futuro?")
2) Ver un verbo conjugado → identificar si es pasado/presente/futuro
3) Completar oraciones con el verbo en el tiempo correcto (selector de opciones)
4) Lista de oraciones → indicar el tiempo verbal de cada una
5) Tres textos (Los osos, Tareas del cuidador, Gina) → clasificar verbos en tabla por tiempo
